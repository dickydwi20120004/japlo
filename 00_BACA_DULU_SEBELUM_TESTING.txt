🔧 QUICK COMMANDS (Jika ada masalah)

Clear cache jika ada issue:
  php artisan cache:clear
  php artisan config:clear
  php artisan view:clear

Check database:
  php artisan migrate:status

Reset database (hapus semua data):
  php artisan migrate:fresh --seed

Refresh composer:
  composer dump-autoload -o

Restart server jika hang:
  taskkill /F /IM php.exe
  php artisan serve

❌ JIKA ADA ERROR

Jika ada error saat testing:

1. Check browser console (tekan F12)
   └─ Lihat error message merah

2. Check Laravel logs:
   └─ storage/logs/laravel.log

3. Coba langkah-langkah:
   └─ Clear cache: php artisan cache:clear
   └─ Restart server: php artisan serve
   └─ Hard refresh browser: Ctrl + Shift + R
   └─ Try incognito mode: Ctrl + Shift + N

4. Jika masih error:
   └─ Baca PANDUAN_PERSIAPAN_TESTING.md section Troubleshooting
   └─ Atau baca VERIFIKASI_LENGKAP_FINAL.md untuk technical details
