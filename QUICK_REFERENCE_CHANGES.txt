✅ NEW JAVASCRIPT FUNCTIONS:

ADMIN PAGES:
  - viewUser(id, name)              Opens user detail modal
  - editUser(id)                    Placeholder for user editing
  - deleteUser(id, name)            Deletes user with confirmation
  - viewDriver(id, name)            Opens driver detail modal
  - editDriver(id)                  Placeholder for driver editing
  - deleteDriver(id, name)          Deletes driver with confirmation
  - viewOrder(id)                   Opens order detail modal
  - updateOrderStatus(id, status)   Updates order status
  - setStatus(newStatus)            Confirms status change
  - deleteOrder(id)                 Deletes order with confirmation

KULINER:
  - searchRestoran()                Real-time search input
  - executeSearch()                 Executes search query (currently shows alert)
  - openFilterModal()               Opens advanced filter options
  - filterByCategory(category)      Filters by food category
  - showAllCategories()             Shows all available categories
  - updateCartBadge()               Updates cart counter in real-time

PRODUK:
  - searchProducts()                Real-time product search
  - executeSearch()                 Validates and searches
  - openProductFilter()             Opens filter options
  - filterProductCategory(cat)      Category filtering
  - addToCart(id, name)             Adds to cart and updates badge
  - openProductCart()               Shows cart status

PROMOSI:
  - filterPromo(category)           Filters promos by category

TRENDING:
  - openTrendingDetail(id, title)   Opens trending detail
  - readTrendingContent(title, desc) Opens article content

SOSIAL:
  - likePost(id)                    Toggles like state with visual feedback
  - toggleComments(id)              Shows/hides comment section
  - sharePost(id)                   Opens native share or fallback
