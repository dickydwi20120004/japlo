## 💻 URLS & ROUTES:

View Tracking Page:
└─ GET /order/track/{orderId}
   └─ Example: /order/track/1

Get Location Data (JSON):
└─ GET /order/location/{orderId}
   └─ Returns: driver_lat, driver_lng, distance, ETA

Update Driver Location:
└─ POST /order/location/update
   └─ Send: order_id, latitude, longitude

Poll Location (AJAX):
└─ GET /order/poll/{orderId}
   └─ Returns: driver_location, status, ETA

## 🔧 BACKEND IMPLEMENTATION:

TrackingController Methods:

1. track($orderId)
   └─ Display tracking page
   └─ Check authorization
   └─ Return HTML view

2. getLocationUpdate($orderId)
   └─ Get current locations (JSON)
   └─ Used for initial load
   └─ Returns: driver_lat, driver_lng, etc.

3. updateLocation(Request)
   └─ Receive driver GPS update
   └─ Validate coordinates
   └─ Store in database
   └─ Returns: success response

4. pollLocation($orderId)
   └─ Poll for location updates (AJAX)
   └─ Used for real-time updates
   └─ Returns: driver_location, status, ETA

## 💡 CUSTOMIZATION OPTIONS:

Change Map Provider:
└─ Edit: L.tileLayer(...) dalam tracking.blade.php
└─ Options: OpenStreetMap, Google Maps, Mapbox

Change Marker Colors:
└─ Edit: icon URL dalam JavaScript
└─ Options: Red, green, yellow, blue, dll

Change Animation Speed:
└─ Edit: setInterval(..., 1000) untuk update interval
└─ Options: 500ms, 1000ms, 2000ms

Change Default Location:
└─ Edit: map.setView([-6.2088, 106.8456], 14)
└─ Change coordinates ke kota Anda

Change Journey Duration:
└─ Edit: progress += 0.005 untuk kecepatan
└─ Lower value = faster, Higher value = slower
